## Maintaining submissions

The sitemap regenerates on each build from public pages, blog entries and published seed offers. It does not currently query live Firestore for newly created course URLs. Search engines periodically revisit the submitted sitemap. After a successful production deployment, run `node scripts/submit-indexnow.mjs` to notify participating IndexNow engines of these public URLs; this script is not yet a deployment hook.

The IndexNow proof key and Bing verification tag are intentionally public ownership records. They are not Firebase, payment or server credentials. Retain them to preserve verification.

Submission, acceptance and indexing are different states. No search ranking score or first-place ranking is asserted by this report.
